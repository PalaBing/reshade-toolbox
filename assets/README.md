# 制作资产

本目录维护可独立使用或跨项目复用的制作资产。现有 [PhotoTemplateStudies](templates/PhotoTemplateStudies/README.md) 收录四个可编辑的照片模板原型，包含预览、方向稿与素材来源记录。

| 分类 | 用途 |
|---|---|
| [templates](templates/README.md) | 可继续编辑的版式、边框与其他制作模板 |
| [resources](resources/README.md) | 图片、纹理、LUT、叠加素材等直接使用的资源 |

仅服务于某个着色器、预设或模块的资产放在该项目的 `assets/`。收录资产时提供用途、格式、来源、使用条件，以及编辑或导出所需的信息。
