# P03 · 绯红夜宴

古典邀请函与拱窗。画幅 3:4，默认输出 2880 × 3840 PNG。

[打开编辑器](index.html) · [返回档案](../../index.html)

## 怎么用

1. 用 Chrome 或 Edge 打开 index.html。
2. 导入本机透明角色 PNG，调整位置和大小。
3. 按需编辑文字、配色和图层。
4. 点击「保存方案」保存 JSON，下次用「读取方案」恢复。
5. 导出 PNG。刷新或恢复初始版式前，先保存需要保留的修改。

适合：坐姿、礼服、人物特写。

可调整：两行标题、邀请文案、日期印章、拱窗位置与宽度、独立装饰。

方案 JSON 内含人物图片。默认页面没有内置个人角色素材，没有自动保存。4K 输出不会补出低分辨率图片本身没有的细节。

初始人物区域留空。人物可越过拱窗，不会被窗口裁切。标题优先使用本机 Bodoni MT，缺少时使用 Times 等备用字体，也可切换中文宋体。
