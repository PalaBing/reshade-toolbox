# P04 · 鸦羽之夜

蓝色法阵与独立前景。画幅 16:9，默认输出 3840 × 2160 PNG。

[打开编辑器](index.html) · [返回案例入口](../../README.md)

## 怎么用

1. 用 Chrome 或 Edge 打开 index.html。
2. 导入本机透明角色 PNG，调整位置和大小。
3. 按需编辑文字、配色和图层。
4. 点击「保存方案」保存 JSON，下次用「读取方案」恢复。
5. 导出 PNG。刷新或恢复初始版式前，先保存需要保留的修改。

适合：大翅膀、武器和横向动作构图。

可调整：法阵明暗、三枚独立眼睛、六片可调羽毛、人物与前景分层。

方案 JSON 内含人物图片。默认页面没有内置个人角色素材，没有自动保存。4K 输出不会补出低分辨率图片本身没有的细节。

初始人物区域留空。羽毛始终位于人物前方。法阵纹样与雾气为生成位图，可调节整体效果；眼睛为独立矢量图形。背景原图 1672 × 941，羽毛原图 1024 × 1536，详见 assets/generation-notes.md。
