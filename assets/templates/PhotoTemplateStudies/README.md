# 照片模板试验档案

一组 FF14 角色照片呈现原型，保存为可回看的本地设计基准。它记录四种版式和图层组织方式，当前按独立原型保留。

**入口：[index.html](index.html)**。用 Chrome 或 Edge 打开即可查看四个模板并进入编辑。无需安装或运行服务器。

| 模板 | 方向 | 默认输出 |
|---|---|---|
| [P01 · JOURNEY](templates/p01-journey/index.html) | 中央人物与横向大字 | 3840 × 2160 |
| [P02 · 橙夜魔女](templates/p02-halloween/index.html) | 橙底剪影与万圣节装饰 | 2880 × 3840 |
| [P03 · 绯红夜宴](templates/p03-crimson/index.html) | 古典邀请函与拱窗 | 2880 × 3840 |
| [P04 · 鸦羽之夜](templates/p04-raven/index.html) | 蓝色法阵与独立前景 | 3840 × 2160 |

## 保留了什么

- templates/：四个可以独立运行的 HTML 原型及使用说明。
- previews/：从干净初始状态截取的版式预览，没有个人角色图片。
- concepts/：P03、P04 的生成方向稿，用于对照构思与实现。
- templates/p04-raven/assets/：法阵底图、透明羽毛与生成记录。HTML 也嵌入相同素材，因此可独立打开。
- NOTES.md：设计重点、素材来源和验证范围。
- MANIFEST.json：归档文件的 SHA-256，方便确认这份基准的内容。

各模板均支持 PNG 导入、文字编辑、方案保存与 PNG 导出；独有功能见对应说明。方案 JSON 含完整人物图片，需自行保存。当前没有自动保存。

4K 指输出画布尺寸；P04 法阵背景原图为 1672 × 941，放大不会补出原图没有的细节。不同电脑字体可能略有差异。

本档案没有复制个人角色 PNG、带角色的成片、角色方案 JSON、第三方参考原图或本机预览服务器。模板只在浏览器中处理选中的文件，没有上传接口。

代码与文档适用仓库根目录许可。生成位图的来源单独记录，不将第三方参考图或游戏角色素材的权利归入代码许可。
