# 设计与验证记录

归档日期：2026-10-26。

## 四次试验留下的基准

- P01：人物、巨型标题和浅色几何元素之间的层次关系；原型基于中心人物大字横幅构图练习，保留当前 v2。
- P02：通过背景、剪影装饰和少量点缀色形成节日主题；参考万圣节魔女插画的路灯、南瓜与人物三角构图，支持镜像。
- P03：先生成空白邀请函方向稿，再用独立矢量图形和文字重建为可编辑版式；人物可以越过拱框。
- P04：复杂背景、角色、前景的独立控制。法阵纹样与雾气作为位图保留；眼睛为矢量图形；六片羽毛复用一张透明素材，各有独立参数。

## 来源与保存范围

P01、P02 为基于参考布局的个人构图练习，参考原图未纳入本档案，不能据此声称参考作品的作者或许可。P03、P04 的方向稿与 P04 两张可用位图由 imagegen 生成；概念预览与可编辑实现分开保存。P04 的生成记录见其 assets/generation-notes.md。几何占位人物不代表 FF14 游戏渲染。

个人角色照片与角色成片不在归档内。

## 验证范围

归档前，四个原型均已有实际 PNG 导出与方案保存恢复检查：P01/P04 为 3840 × 2160，P02/P03 为 2880 × 3840。P01 曾用实际角色素材检查；P02 检查过 PNG 导入及修改参数；P03/P04 使用透明测试图检查独立图层参数及刷新恢复。这些检查对应原型功能，不是游戏内着色器验证。

归档时重新检查 HTML 脚本语法、重复元素 ID、相对链接和初始预览。模板 HTML 按字节复制，功能代码未重构；MANIFEST.json 记录归档内容。

画布拖动功能已接入，但此前多数功能检查使用编辑控件完成。当前档案用于回看与继续实验，没有对全部角色宽高比、浏览器或低性能设备作完整兼容测试。
