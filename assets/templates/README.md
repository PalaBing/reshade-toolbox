# 制作模板

用于保存可编辑的制作结果及实现案例，供后续需求参考视觉思路、复用制作流程与技术。

| 模板系列 | 内容 | 使用入口 |
|---|---|---|
| [PhotoTemplateStudies](PhotoTemplateStudies/README.md) | P01 人物大字横幅、P02 万圣节装饰、P03 绯红邀请函、P04 法阵前景合成 | [案例与技术入口](PhotoTemplateStudies/README.md) |

PhotoTemplateStudies 的四个 HTML 原型可在本地浏览器中直接打开，支持透明 PNG 导入、文字编辑、方案保存与 PNG 导出。默认输出、素材来源与验证范围见系列说明。

每个模板系列集中保存可编辑源文件、示例或预览及使用说明。说明应包含编辑软件、尺寸、可替换区域、外部素材来源和导出步骤。
